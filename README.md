# Windows Setup Hub (`win-program-launcher`)

Веб-каталог и desktop-лаунчер (`WinPackApp.exe`) для быстрой настройки и обслуживания ПК на Windows. Проект создан, чтобы не искать каждый раз ссылки на нужные программы и утилиты по разным сайтам — всё собрано в одном тёмном интерфейсе с профилями под типовые задачи, поиском и быстрым открытием выбранных позиций.

---

## Зачем нужен этот проект

При чистой установке Windows, настройке ПК для клиента, лечении от вирусов или проверке старого железа обычно уходит много времени на ручной поиск проверенных дистрибутивов и утилит.

**Windows Setup Hub** решает эту задачу за счёт двух частей:
1. **Веб-интерфейс (`index.html`)** — каталог программ и утилит, разбитый по категориям, с поиском, готовыми профилями подбора и массовым открытием отмеченных ссылок в браузере (а также поддержкой скачивания ZIP-архивов, если указан `zipUrl`).
2. **Лаунчер `WinPackApp.exe` (`app.py`)** — исполняемый файл для Windows, который проверяет доступность площадок размещения (например, Vercel и GitHub Pages с автоматическим резервным переключением) и открывает интерфейс в отдельном окне браузера в режиме `--app`.

---

## Основные возможности

* **Категории программ и утилит:**
  * Браузеры (Google Chrome, Mozilla Firefox, Яндекс Браузер, Brave, Zen Browser и др.).
  * Антивирусы и средства проверки/лечения системы (Kaspersky Free, Dr.Web CureIt!, Malwarebytes, KVRT и др.).
  * Средства обхода блокировок и сетевые клиенты (`zapret`, `GoodbyeDPI`, `Happ`, `Hiddify Next`, `AmneziaVPN`, `v2rayN`).
  * Мессенджеры и удалённый доступ (Telegram Desktop, AyuGram Desktop, WhatsApp, AnyDesk, RustDesk).
  * Торренты и медиаплееры (qBittorrent, VLC, MPC-BE, AIMP).
  * Архиваторы, рантаймы и диагностика железа/дисков (7-Zip, WinRAR, Visual C++ Redistributable, DirectX Runtime, CrystalDiskInfo, CPU-Z, HWMonitor, WizTree, Revo Uninstaller).
* **Готовые профили:** быстрый выбор набора программ под конкретную задачу (быстрый старт клиента, связь и обходы, лечение ПК, слабый/старый ПК, всё подряд).
* **Поиск и фильтрация:** быстрый поиск по названию, описанию и тегам, переключение между разделами, счётчики выбранных позиций и ZIP-ссылок, снятие выбора.
* **Резервирование адресов в лаунчере:** список `URLS` с проверкой доступности, чтобы при проблемах с одним хостингом лаунчер переключался на запасной.

## Как пользоваться

### Вариант 1. Скачать готовый `WinPackApp.exe` (рекомендуемый)
1. Перейди в раздел **Releases** на странице репозитория.
2. Скачай актуальный файл `WinPackApp.exe` из блока **Assets**.
3. Запусти `WinPackApp.exe` — лаунчер проверит доступный адрес сайта и откроет интерфейс в отдельном окне.

### Вариант 2. Открыть веб-версию в браузере
* Перейди по ссылке развёрнутого сайта (GitHub Pages / Vercel) либо открой `index.html` локально в браузере.
* Выбери готовый профиль или отметь нужные программы чекбоксами.
* Нажми **«Открыть отмеченные»** (если браузер заблокирует открытие нескольких вкладок подряд, разреши всплывающие окна для сайта и повтори нажатие).
